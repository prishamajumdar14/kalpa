# KALPA

KALPA is a non-linear 2.5D narrative game set in the Andaman Sea. You move through a flooded research station, choose where to go and in what order, and piece the story together from what people tell you.

**This is a preview.** The prologue cinematic is still coming; for now the game shows a "Cinematic coming soon" card with a Skip button before the cockpit.

## How to play

- Click or tap the glowing hotspots to look at things, talk to people and move between rooms.
- Press Space or Enter to advance dialogue.
- Press the number keys to pick a choice.
- Press Esc to open settings.

## Run locally

```
npm ci && npm run dev
```
